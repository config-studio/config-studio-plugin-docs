# Config Studio Plugin Docs — AI Agent Rules 🚀

## 🛠️ Главные регламенты документации плагинов
1. **Единый источник спецификации:** Репозиторий содержит официальную спецификацию формата `.cspkg`, манифеста `plugin.json`, TypeScript definitions `config-studio.d.ts` и SDK для разработчиков плагинов.
2. **Шаблон расширения:** Разработчикам расширений предоставляется шаблон `config-studio-plugin-template` с готовым CI/CD рабочим процессом `.github/workflows/release.yml`.
3. **Обязательный релиз через GitHub Workflow:** Каждое расширение должно публиковаться в виде официального GitHub Release через GitHub Actions с прикреплением скомпилированного `.cspkg` и SHA-256 чексумм.
